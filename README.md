# 📰 AI-Powered News Aggregator

A full-stack news aggregator web application built using **React** (frontend) and **Flask** (backend) that fetches top headlines from the web and summarizes them using **OpenAI's GPT API**.

---

## 🔍 Features

- 🗞️ Fetches real-time news articles using a News API
- 🤖 AI-powered summarization using OpenAI GPT
- 🌐 Beautiful and responsive frontend built with React
- 🔁 Backend API built with Flask and Python
- 📦 Deployable build for production

---

## 🛠️ Tech Stack

| Layer     | Technology             |
|-----------|------------------------|
| Frontend  | React, Axios, CSS      |
| Backend   | Flask, Python          |
| AI        | OpenAI GPT API         |
| Data      | NewsAPI / Other API    |
| Build Tool| react-scripts          |
