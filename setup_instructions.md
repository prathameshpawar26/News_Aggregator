# Setup Instructions

Before proceeding with the project setup, please ensure you have the following prerequisites installed:

1. **Install Node.js and npm**
   - Download Node.js from: https://nodejs.org/
   - Choose the LTS (Long Term Support) version
   - Run the installer and follow the installation steps
   - After installation, verify by opening a new terminal and running:
     ```bash
     node --version
     npm --version
     ```

2. **Install Python**
   - Download Python from: https://www.python.org/downloads/
   - Make sure to check "Add Python to PATH" during installation
   - Verify installation by opening a new terminal and running:
     ```bash
     python --version
     ```

3. **Get API Keys**
   - Get a free NewsAPI key from: https://newsapi.org/
   - (Optional) Get an OpenAI API key from: https://platform.openai.com/

After installing these prerequisites, please close and reopen your terminal/IDE, then continue with the project setup as described in the README.md file.
